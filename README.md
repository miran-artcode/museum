# 허구의 아카이브 — 창작 과정 기록실

고등학교 1학년 미술 8차시 단원 「실재한 적 없는 유물 이미지로 구성한 허구의 아카이브 전시」의 수업 자료와 학생 기록지, 교사 대시보드를 담은 웹 애플리케이션입니다.

- 학생: 학번 + 별명 + 숫자 4자리로 입장, 강의 노트와 학습지 작성, 자동 저장, 사전·사후 창의성 설문(24문항, 제출 후 잠금)
- 교사: 관리자 코드로 입장, 차시별 공개 설정, 진행 현황, 기록 열람, 차시별 살펴본 시간, 루브릭 채점, 창의성 6축 대시보드(유창성·융통성·독창성·정교성·과정·멀티모달), 설문 대시보드(사전·사후 척도 비교, 효과크기, 문항별 변화, 원자료 CSV), CSV 내보내기
- 수업 편집: 관리자 교사가 교사 화면에서 차시별 발문·학습지 질문·이론 본문·그림·작품 설명 링크를 직접 고침. 고친 내용은 학생 화면에 바로 반영되고 「원래대로」로 원본 복구
- 전시장: 공개로 설정된 작품을 작품 번호로 관람 (1차 관람은 명제표 가림)
- 번역 사다리(3차시): 관찰 절차 정하기 → 장면 채집 → 문제 좁히기 → 사회를 드러내는 방법 정하기 → 보이지 않는 것 가르기 → 사물 찾기 → 흔적으로 옮기기 → 되돌려 읽기 → 진술 확정의 아홉 계단. 관찰 방법 다섯(표류·정점 관찰·동선 지도·사물 목록·소리 산책)과 사회참여 미술의 갈래 여덟(증언·가림·아카이브·파라픽션·포렌식·제도비평·개입·관계)을 학습하고 고른 뒤, 고른 이유와 그 방법의 위험을 다룰 방도까지 쓰게 합니다
- 연구 자료: 「연구」 탭에서 익명 처리된 참여자·계단·문장 단위 CSV와 기술통계·변수사전·원고초안 마크다운을 내려받습니다
- 연구 기반: Kaufman·Beghetto 4C 모형의 little-c 창의성을 자기보고 설문(RIBS·SSCS·창의성 성장 신념 등 번안) × 행동 지표(6축) × 질적 기록(변화 쌍·성찰·문제 발견)으로 삼각검증하는 단일집단 사전·사후 혼합 설계. 상세는 교사 화면 「수업 안내」 탭의 연구 설계 참고 항목에 있습니다.

## 5. 사회참여의 과정 — 번역 사다리 아홉 계단

3차시의 기록 B1~B7이 「번역 사다리」입니다. 사회문제를 **어떻게 관찰할지 정하는 일**에서 시작해, 사회참여 미술이 **사회를 드러내 온 여러 방법 가운데 하나를 고르고**, 보이지 않는 대상을 사물의 흔적으로 옮기기까지를 아홉 계단으로 나눈 것입니다. 각 계단은 앞 계단의 산출물을 재료로 삼고, 학생 화면에는 계단 띠가 늘 떠 있어 지금 어느 자리인지와 앞에서 무엇을 가져왔는지가 보입니다.

| 계단 | 하는 일 | 학생이 내놓는 것 | 기록 칸 |
|---|---|---|---|
| T1 | 관찰 방법을 정한다 | 다섯 절차 중 하나, 고른 이유, **그 방법이 놓치는 것과 메울 방도** | `s3o.*` (B1) |
| T2 | 장면을 모은다 | 고른 절차대로 모은 장면 3개 이상 | `s3a.scenes` (B2) |
| T3 | 문제로 좁힌다 | 문제 하나, 나와 만나는 때와 곳, 접은 후보와 견준 이유 | `s3a.*` (B2) |
| T4 | 사회를 드러내는 방법을 정한다 | 여덟 갈래 중 하나, 이유, 접은 갈래와 이유, **위험을 다룰 방도**, 단원 형식으로 실현할 방법 | `s3e.*` (B3) |
| T5 | 보이지 않는 것을 가른다 | 3개 이상 + **왜 보이지 않는지 다섯 갈래**, 고른 하나 | `s3t1.*` (B4) |
| T6 | 사물 후보를 찾는다 | 사물 3개(어디에·누구의 몸이·**어떤 동작으로** 닿는가), 고름/접음 | `s3t2.*` (B5) |
| T7 | 흔적으로 옮긴다 | 자리·모양·**동작·빈도·기간**의 흔적 표, 번역 진술 초안 | `s3t3.*` (B6) |
| T8 | 거꾸로 읽어 본다 | 짝의 읽기, 의도와의 거리, **되돌아간 계단과 고친 것** | `s3t4.reverse` (B7) |
| T9 | 진술을 확정한다 | 확정 진술 + 초안 대비 무엇이 달라졌는가 | `s3t4.*` (B7) |

T1과 T2는 2차시 끝에 안내해 **한 주 과제**로 돌립니다. 3차시 120분은 T3부터 T9까지를 다룹니다.

### 5.1 T1 — 장면은 어떻게 모으는가 (관찰 절차 다섯)

“사회문제에 관심을 가지고 잘 살펴보라”는 지시는 관찰을 가르치지 못합니다. 절차를 명시하고, 절차마다 **잘 잡히는 것과 놓치는 것**을 함께 줍니다. 학생은 하나를 골라 그대로 모으고, 그 방법의 한계를 직접 적습니다. 표의 칸 이름과 예시는 고른 절차에 맞게 바뀝니다.

| 절차 | 이론적 출처 | 잘 잡아냅니다 | 놓칩니다 |
|---|---|---|---|
| 표류 | 기 드보르 「표류의 이론」(1956), 상황주의 심리지리 | 문제가 어디 있는지 모를 때. 익숙해서 안 보이던 자리 | 우연에 기대므로 반복·정시(定時)의 일 |
| 정점 관찰 | 윌리엄 화이트 「작은 도시 공간의 사회적 삶」(1980) 시간 표집 | 반복과 시간이 쌓여야 드러나는 일 | 고른 한 자리 바깥 |
| 동선 지도 | 케빈 린치 「도시의 이미지」(1960) 인지 지도 | 문제와 나의 접점, 들어가 보지 못한 경계 너머 | 내 동선 바깥의 일 |
| 사물 목록 | 조르주 페렉(1975), 마크 디온의 현장 수집 | 너무 당연해서 아무도 세지 않는 것 | 사라진 것, 오지 않는 사람 |
| 소리 산책 | 머레이 셰이퍼 음향생태학, 베스터캄프 사운드워크 | 벽·문 뒤에서 일어나 눈에 안 보이는 일 | 소리 없는 일, 이미 끝난 일 |

### 5.2 T4 — 사회를 드러내는 여덟 갈래

사회참여 미술은 하나의 양식이 아니라 **방법의 선택**입니다. 같은 문제를 다뤄도 갈래에 따라 관람자가 하는 일과 작가가 지는 책임이 달라지고, 갈래마다 위험이 따로 있습니다. 학생은 여덟 갈래를 읽고 자기 작업이 설 자리를 정한 뒤, **고른 이유 · 접은 갈래의 이유 · 그 갈래의 위험을 다룰 방도 · 이 단원의 형식으로 실현할 방법** 네 칸을 씁니다.

| 갈래 | 대표 작업 | 관람자가 하게 되는 일 | 이 방법의 위험 |
|---|---|---|---|
| 증언과 기록 | 임흥순 「위로공단」(2014) | 몰랐던 사실을 알게 됨 | 대리 재현, 고통이 볼거리가 됨 |
| **가림과 우회** | 알프레도 자 「르완다 프로젝트」 | 빈자리를 스스로 채움 | 너무 가리면 전달 안 됨, 회피로 읽힘 |
| 아카이브와 분류 | 마크 디온의 수집과 진열 | 목록의 빈칸을 봄 | 형식이 그럴듯하면 내용을 안 따짐 |
| **허구와 파라픽션** | 폰트쿠베르타 「Fauna」, 아틀라스 그룹 | 무엇을 근거로 믿었는지 되짚음 | 고지 없이 유통되면 위조 |
| **증거와 포렌식** | 포렌식 아키텍처 | 사물이 증인이 됨 | 인과가 어긋나면 전부 무너짐 |
| 제도비평 | 브로타에스(1968), 한스 하케(1971) | 작품을 작품으로 만든 틀을 봄 | 미술 안쪽 이야기에 머물러 문제와 끊김 |
| 개입과 전술 | 보디치코의 건물 프로젝션 | 안 보이던 규칙이 어긋남으로 드러남 | 놀라게 하는 데서 끝남, 남의 자리 침범 |
| 관계와 대화 | 보이스, 부리요 「관계미학」(1998), 케스터(2004) | 관람자가 참여자가 됨 | 비숍(2004) — 화합만 남고 갈등이 지워짐 |

**굵게 표시한 세 갈래가 이 단원의 형식입니다.** 결과물(실재한 적 없는 유물의 기록 사진 + 명제표)은 가림과 우회 · 허구와 파라픽션 · 증거와 포렌식을 겹쳐 놓은 것입니다. 이 사실을 학생에게 감추지 않고 미리 밝힙니다 — 감추면 학생은 결국 교사가 원하는 답을 짐작하기 때문입니다. 다른 갈래를 골라도 되며, 그 경우 고른 갈래가 유물 이미지·명제표·진열 가운데 어느 요소를 맡을지 스스로 정해 적습니다.

### 5.3 T5 — 왜 보이지 않는가 (다섯 갈래)

보이지 않는 것을 곧바로 그리라고 하면 대부분 상징(눈물·사슬·시든 꽃)으로 도망갑니다. ‘무엇이 안 보이는가’ 대신 **‘왜 안 보이는가’**를 먼저 묻고, 이유마다 다음 계단에서 찾을 곳을 정해 줍니다.

| 갈래 | 뜻 | 다음 계단에서 찾는 것 |
|---|---|---|
| 시간에 흩어져서 | 여러 번 쌓여야 드러남 | 닳음·눌림·색바램·손자국 광택 |
| 자리에 가려져서 | 벽·문·경계 뒤에 있음 | 안쪽 면·바닥 면·이음매·밑동 |
| 기록이 없어서 | 세지도 적지도 않음 | 손으로 쓴 번호·눈금·표시 테이프 |
| 이미 사라져서 | 지금은 자리만 남음 | 떼어 낸 자국·빈 나사 구멍·색이 다른 사각형 |
| 너무 당연해서 | 아무도 문제로 세지 않음 | 문턱 높이·손잡이 위치·안내문 글자 크기 |

### 5.4 사고의 발전과 변화가 남는 곳

- **세 번의 선택과 그 이유** — T1 관찰 절차, T4 드러내는 방법, T5 비가시성 갈래. 세 지점 모두 고르기만 하는 것이 아니라 고른 이유와 접은 것의 이유를 함께 적습니다. 고르기만 하고 이유 칸이 비어 있으면 고른 것이 아니라 찍은 것입니다.
- **진술 버전** — 학생이 「이 문장으로 확정」을 누를 때마다 그때의 문장이 따로 저장됩니다. T7의 처음 문장과 T9의 확정 문장이 이 단원의 사전·사후 자료가 되고, 그 사이 버전들이 사고의 이동 경로가 됩니다.
- **되돌아간 계단** — T8에서 짝이 다르게 읽었을 때 어느 계단으로 돌아가 무엇을 고쳤는지가 그대로 기록됩니다. 되돌림은 실패가 아니라 자기 판단을 뒤집은 흔적입니다.
- **구체성 지수** — 위치·재질·변형·수량을 가리키는 말을 어휘 사전으로 세어 0~100으로 환산합니다. 추상어가 관찰 가능한 말로 바뀌었는지를 가리키는 표지이며, 작품의 좋고 나쁨과는 무관합니다.

교사 화면에서 보는 곳은 두 군데입니다. **「사고 과정」 탭**은 학급 전체의 계단별 도달률, 관찰 절차와 드러내는 방법의 선택 분포(그리고 이유·위험·형식 네 칸의 기록률), 비가시성 갈래 분포, 구체성 초안→확정 이동 그래프, 되돌아간 계단 분포를 보여 줍니다. 학생 상세의 **「번역 사고」 탭**은 한 학생의 두 선택과 그 이유, 아홉 계단, 진술 버전 이력, 되돌림 기록, 사다리에 남은 글 전체를 보여 줍니다.

## 6. 연구 자료로 바꾸기 — 교사 화면 「연구」 탭

| 파일 | 한 행의 단위 | 논문의 어느 자리 |

| `연구자료_참여자단위.csv` | 참여자 1명 | 기술통계·상관·사전 사후 비교. 통계 프로그램에 그대로 올림 |
| `연구자료_계단단위.csv` | 참여자 × 아홉 계단 | 계단별 도달·글자 수·구체성·편집 시각. 반복측정 구조 |
| `연구자료_코딩시트.csv` | 참여자 × 항목 × 문장 | 질적 분석. 1차 자동 표지가 붙고 `code_1`·`code_2`·`memo`는 빈칸 |
| `연구자료_사전사후쌍.csv` | 참여자 × 비교 쌍 | 같은 물음에 두 번 답한 자리의 원문 인용 |
| `기술통계.md` | — | 표 1~5 (기술통계·계단 도달·갈래 분포·사전 사후·상관) |
| `변수사전.md` | — | 연구 방법의 측정 도구 절. 조작적 정의와 산출식 |
| `원고초안.md` | — | 연구 방법·결과의 사실 서술을 수치까지 채운 초안 |

원고 초안은 수치가 들어가는 문장만 자동으로 채우고, 해석·논의·선행 연구는 「연구자 서술」 자리로 비워 둡니다. CSV는 BOM을 붙여 저장하므로 엑셀에서 한글이 깨지지 않습니다.

**수치를 읽을 때 지킬 것.** 구체성 지수는 어휘 사전 기반의 간이 지표이며 형태소 분석이나 문맥 판단을 하지 않습니다. 논문에 실을 때는 코딩 시트에서 표본을 뽑아 사람이 교차 검토하고 그 신뢰도를 함께 보고해야 합니다. 계단의 완료 판정도 항목이 채워졌는지만 보고 내용의 질은 보지 않습니다. 한 학급 단일 집단 자료이므로 유의확률은 산출하지 않으며, 사전·사후 표의 t 값과 효과크기는 참고 계산입니다.

## 7. 파일 구성

```
public/index.html      화면 뼈대

소스를 고친 뒤에는 다시 번들해야 합니다.

npm install

```

## 9. 수업 내용 고치기 — 교사 화면 「수업 편집」 탭

차시별 수업 자료는 코드에 원본이 들어 있고, 교사가 고친 것만 `misc/lessonEdits` 문서에 따로 쌓입니다.
화면에 그릴 때 원본 위에 고친 내용을 얹으므로 **원본은 지워지지 않고**, 「{n}차시 원래대로」를 누르면 그 차시가 처음 자료로 돌아갑니다.

| 고치는 것 | 어디에 나타나는가 |
|---|---|
| 차시 제목 · 학습 목표 | 학생 강의 노트와 교사 안내서 |
| 오늘의 발문 | 학생 강의 노트 맨 위의 붉은 상자 |
| 120분 수업 흐름 (단계 · 시간 · 활동) | 교사 화면에만 |
| 읽기 자료 — 소제목, 이론 본문 | 학생 강의 노트의 접이식 자료 |
| 단계별 발문 | 읽기 자료 안의 「생각해 볼 물음」 상자 |
| 그림 · 사진 | 이론 본문 아래. 파일을 올리거나 그림 주소를 붙여넣음 |
| 작품·자료 표와 설명 링크 | 자료 표의 「보는 이유」 칸 아래 링크 단추 |
| 학습지 발문과 생각 단계 | 배움 확인 · 탐구 질문의 물음 |
| 설계 근거 | 교사 화면에만 |

- 본문은 **빈 줄 하나로 문단**을, 목표·발문·생각 단계는 **한 줄에 하나씩** 나눕니다.
- 저장을 누르면 접속해 있는 학생 화면에 곧바로 반영됩니다. 수업 중에 발문을 바꿔도 됩니다.
- 학습지 항목 이름(`l1.q1` 같은 것)은 바뀌지 않으므로, **발문을 고쳐도 학생이 이미 쓴 답은 그대로 남습니다.**
- 그림은 올릴 때 긴 변 1400px·약 0.7MB로 자동으로 줄어듭니다. 남의 사진·그림은 수업 목적의 인용 범위를 지키고 출처 표기 칸을 채웁니다. 미술관 소장품처럼 링크로 충분한 자료는 파일을 올리는 대신 설명 링크로 거는 편이 안전합니다.
- 작가와 작품 이름에는 위키백과·테이트·워커 아트센터 등 설명 사이트 링크가 기본으로 붙어 있고, 이 탭에서 이름과 주소를 고치거나 더 넣을 수 있습니다. 링크는 모두 새 창에서 열립니다.

## 10. 운영에서 지킬 것

- 별명에 실명을 쓰지 않습니다. 얼굴 사진과 개인정보는 어디에도 입력하지 않습니다.
- 관찰 사진·전시 영상은 사람의 얼굴이, 현장 소리는 사람의 목소리가 담기지 않게 찍고 녹음하도록 안내합니다.
- 확정 성적은 학교 시스템에 별도로 입력하고, 이 앱은 수업 기록과 채점 보조 용도로 씁니다.
- 학생이 비밀번호를 잊으면 Firebase 콘솔 Authentication 목록에서 해당 학번 계정을 삭제합니다. 같은 학번으로 다시 입장하면 새 비밀번호로 등록되고 기록은 학번에 남아 이어집니다.
- Firestore 무료 한도는 하루 읽기 5만 건, 쓰기 2만 건입니다. 한 학급 25명 기준으로 여유가 있습니다.
